# Documentação Oficial do Projeto

## 📌 Visão Geral
Este espaço é dedicado a detalhar a arquitetura, instruções de uso, guias operacionais e configurações da aplicação.

---

## 🚀 Como Usar este Template
1. Clique no botão **Use this template** na página principal do repositório template.
2. Defina o nome do novo repositório para o seu projeto.
3. Edite os ficheiros dentro da pasta `/docs` para atualizar este portal de documentação.
